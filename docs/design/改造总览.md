## 2. 关键事实与调研结论

归档文档：

- `docs/design/ccswitch-v4-ui-spec.md` —— cc-switch v4.0.31 设计规范（双主题 token、布局骨架、11 类组件解剖、Qt/QSS 落地映射），基于真实源码与截图，含行号依据。
- `docs/design/python-to-cpp-port-spec.md` —— 旧 Python 编排逻辑的逐行为清单、realesrgan/ffmpeg 命令行契约、输出命名差异、C++ 类划分与 20 条验收用例。
- `docs/design/ffmpeg-integration.md` —— FFmpeg 源码内嵌方案与 libav\* 封装层说明。
- `docs/ci.md` —— 质量门禁的一键命令、平台差异与降级行为（R6 交付物）。

影响实现方式的硬结论：

1. **realesrgan 退出码不可信**：失败时仍返回 0，仅在 stderr 打印 `decode/encode image ... failed`；进度输出也全在 stderr，形如 `16.67%`。成功判定与进度解析都必须据此重写。
2. **singleproc 在 Windows 上原本完全无法编译**（`poll.h`/`flock`/`getuid`/`O_NOFOLLOW`/AF_UNIX 都不存在），本轮新增 Win32 后端（锁 + 命名管道门铃），公开 API 与 POSIX 语义保持不变。
3. **cxx_ci 支持 CMake**；Windows 下 `[tools].make` 默认 `nmake` 必须覆盖为 `mingw32-make`，本工程同时显式使用 `-G Ninja` 生成器（`ci.toml` 已处理）。
4. **超分引擎只有 Windows PE**：`bin/realesrgan/realesrgan-ncnn-vulkan.exe` 在 Linux 上不可执行，测试按平台 `QSKIP`；Linux 超分运行需自备引擎（当前未支持/未验证）。
5. **视频输出 GIF 不支持**：UI 历史选项仍含 gif，原生链路会明确报错；输入 GIF 可拆帧后按受支持容器输出。

## 3. 架构决策

### 3.1 构建系统

- 以 **CMake + Ninja 为唯一权威构建**，qmake `.pro` 已移除（避免双份源文件清单漂移）。
- 目标拆分：
  - `resr_core`：domain / infrastructure / model / common / utils（不依赖 Qt Widgets）
  - `resr_ui`：view / controller（依赖 Widgets、Multimedia）
  - `real-esrguisoft`：`main.cpp` + 资源（`RESR_APP_VERSION` 版本注入）
  - `resr_tests` / `resr_media_tests`：注册到 `ctest`
- 三方库以 `third_party/<name>` 子目录 + `add_subdirectory(... EXCLUDE_FROM_ALL)` 引入，各自保持独立 CMake 与文档。

### 3.2 分层依赖

保持原有 `View → Controller → Model → Infrastructure → Domain → Common` 单向依赖，不得反向。

### 3.3 主题与样式

- Qt QSS 没有变量机制，采用 **`{{token}}` 占位 + 运行时替换**：
  - `resources/theme/app.qss.in`（壳层与通用控件样式）
  - `resources/theme/panels.qss.in`（面板私有样式）
  - `src/view/theme/theme_tokens.h/.cpp` 提供亮/暗两套 token，`ThemeManager` 负责替换、加载与切换。
- 主题三态：浅色 / 深色 / 跟随系统，`QSettings` 持久化。

### 3.4 媒体处理

- 图片：`QImage` 读写 + 外部 `realesrgan-ncnn-vulkan.exe`（保留，官方最新）超分。
- 视频：通过链接 `libav*` 直接完成探测、拆帧、编码，**不再调用 ffmpeg.exe**；音频优先 stream copy。
- `bin/ffmpeg` 整个目录删除；FFmpeg 源码内嵌于 `third_party/ffmpeg`，提供跨平台构建脚本，构建时优先复用系统 FFmpeg（pkg-config）。
- `bin/realesrgan`（引擎 + models）保留，`bin/exe`、`bin/src`、`bin/doc` 删除。

### 3.5 用户设置与引擎定位

- `src/common/appsettings.*`：`QSettings` 持久化 `engine/path`（空 = 自动发现），组织 / 应用名与 `ThemeManager` 一致。
- `ExeCommand` 引擎定位优先级：**设置页手动指定（bin / bin/realesrgan / exe 文件）→ 自动发现回退（从程序目录向上找 bin/realesrgan）**；手动路径无效时回退自动发现并在设置页提示，不静默改写用户设置。
- 每次「开始处理」按当前设置重新解析引擎目录，改设置无需重启。
- 并发：当前为**单任务串行**，没有可配置并发数——设置页如实说明，不提供伪设置。
- 线程数：高级参数 `线程数`（Real-ESRGAN `-j`，`load:proc:save`）已接入两条链路的 `upscale_arguments()`；TDR 加固后默认 `1:1:2` 且**总是显式传 `-j`**，空/非法值回退 `1:1:2` 并记日志；图块 `-t` 同样总是显式传（自动=安全默认 256，范围 32–1024），崩溃时用 `-t 128 -j 1:1:1` 自动重试一次。

### 3.6 界面语言（i18n）

- Qt `QTranslator` + 预生成 `.qm`（qrc 嵌入）：源码中文为翻译源串，英文翻译源
  `resources/i18n/app_en.ts`（lupdate 生成、人工补译）、运行时资源 `app_en.qm`。
- `LanguageManager`（`src/common/`，仅 QtCore，入 `resr_core`）负责选择/持久化
  （QSettings `ui/language` = zh/en/system，切换即写并 sync）/translator 装卸/
  `language_changed` 信号；`RESR_UI_LANG` 供自动化启动覆盖（不写盘）。
- **实时切换**：`set_language()` 保存→换 translator→emit；`MainWindow`
  先 `retranslate_all()` 逐面板/控件重设文案（组合框用 itemData 保留选择），
  `AppController` 后重下发动态状态，保证「视图先重译、控制器后覆盖」。
- 翻译范围：用户可见文案（视图/对话框/过滤器/状态与错误/领域显示名）；日志、
  测试、CLI 与领域规范值（`string_to_*`）不翻译。

## 6. 本轮收尾记录与关键决策

### 6.1 排版收口（R6 配套）

- 用从存量源码反推的 `.clang-format` 对全仓 C++ 源码（`main.cpp` / `src/` / `tests/`，
  排除 `third_party/`、资源与构建目录）做一次格式化收口：**104 个文件 → changed 0**。
- 规则要点：Tab 缩进（显示宽度 4）、Allman 大括号、返回值独占一行、指针/引用靠
  变量名（`const QString &v_x`）、80 列、二元/三目运算符换行前置、
  `Cpp11BracedListStyle: false`、不排 include、不重排注释。
- 收口时微调一处：`BreakStringLiterals: false`，避免把超长中文串自动拆成相邻字面量
  拼接（格式化不改字符串字面量）。
- 排版只由 `standardize.py --check/--apply` 执行，后续新代码有 diff 时先看
  `build/standardize/standardize.diff` 再 apply。

### 6.2 静态检查选型（R6 配套）

- `audit.toml` 当前**只启用 `compat`**（纯文本扫描、无外部依赖，Windows/Linux 一致）。
- 原建议的 `std_concurrency` 规则**暂缓启用**：当前会命中 4 条既有代码——
  `src/infrastructure/media/ffmpegutils.cpp:3` 的 `#include <atomic>`、
  `src/model/videoprocessservice.cpp:25` 的 `#include <atomic>`、
  `src/model/videoprocessservice.cpp:652/653` 的 `std::atomic<bool>` 成员。
  在替换为 `QAtomicInt` / 去掉 `<atomic>` 之前启用会让门禁永久变红。当前用
  0 命中的 `variadic_template` 作回归护栏；清理上述 3 处后把
  `"std_concurrency"` 加回 `rules` 即可（步骤见 `docs/ci.md` §4）。
- `tidy` / `cpd` / `asan` / `valgrind` 在 Windows 缺依赖，`enabled = false` 并逐项
  注释原因；Linux/WSL 上可用显式子命令补跑（`docs/ci.md` §6）。
- `standardize` 只做 clang-format 排版（`tidy = false`），与 `cxx_audit` 的 tidy
  职责分离，避免 Windows 上因缺 tidy/编译数据库误报。

### 6.3 测试基建修复

- `project_root()` 从「`applicationDirPath()/../..`」改为**向上查找同时含
  `CMakeLists.txt` 与 `input/` 的目录**（`build/ci`、`build-r6` 等嵌套构建目录均正确）；

| 风险 | 说明 | 缓解 |
|---|---|---|
| realesrgan 进程退出码不可信 | 失败返回 0 | 以产物 + stderr 关键字判定 |
| 视频临时帧磁盘占用 | 1080p 长视频拆帧可占数 GB | 临时目录可配置、任务结束强制清理、超分与编码分块流水 |
